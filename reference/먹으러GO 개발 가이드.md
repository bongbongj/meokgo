## 6. 닉네임 규칙

- 1 ~ 10자 (공백 제외) — 협의 필요
- 한글, 영문, 숫자만 허용. 특수문자와 이모지 불가
- 앞뒤 공백 자동 제거. 공백만 입력 시 버튼 비활성
- 카운터 n/10 — 입력 필드 안쪽 우측, 기본 #9A9A9A, 10자 도달 시 #F55B45
- 같은 탐험방 내 중복 불가 (전역 중복은 허용)
- 저장 위치: 방별 participant.nickname / 앱 01 화면 값은 기기 로컬 기본값

## 7. 사진 규격

- 최소 1장, 최대 4장 (0장이면 미리보기 비활성)
- 형식 JPG / PNG — 협의 필요
- 장당 10MB 이하 — 협의 필요
- 업로드 시 가로 1080px 기준 리사이즈 — 협의 필요
- 선택하지 않은 슬롯은 템플릿에서 제외 (빈칸 노출 안 함)

## 8. 퀘스트 규칙

- 카테고리 6종: 식당 / 탐색 / 메뉴 / 분위기 / 음식 문화권 / 메뉴 수
- 투표 화면에 카테고리당 1개씩 총 6개 노출
- 참여자당 1 ~ 3개 선택 (0개면 제출 불가)
- 마감 전까지 수정 가능. 마지막 제출만 집계
- 최근 3회 탐험에서 쓴 퀘스트는 제외 — 협의 필요
- 후보가 3개 미만이면 조건 재설정 안내 — 협의 필요
- 확정: 득표순 상위 3개
- 동점 시: 먼저 투표된 퀘스트 우선, 그래도 같으면 목록 노출 순서 — 협의 필요

## 10. 탐험 상태 enum

| 값 | 의미 | 전환 조건 |
| --- | --- | --- |
| WAITING | 참여자 모집 중 | 탐험방 생성 직후 |
| VOTING | 퀘스트 투표 중 | 방장이 투표 시작 |
| CONFIRMED | 퀘스트 3개 확정 | 방장이 투표 마감 |
| IN_PROGRESS | 탐험 수행 중 | 확정 화면에서 시작 |
| DONE | 종료 | 3/3 완료 후 종료 |
| CANCELED | 취소 | 방장이 나감 |

두 클라이언트가 이 값으로 화면을 분기하므로 임의 문자열 추가 금지.
